cachy.koresent.dev

Personal binary repository for CachyOS.

Configuration

Append the repository block to /etc/pacman.conf:

[koresent]
SigLevel = Optional TrustAll
Server = https://cachy.koresent.dev/$arch

Synchronize package databases and install target packages:

sudo pacman -Syu
sudo pacman -S kclip kfont kgreet klock korob snap-hud sweep
